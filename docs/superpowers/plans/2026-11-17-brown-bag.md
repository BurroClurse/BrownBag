# Brown Bag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the starter SMART patient app into Brown Bag: one deduplicated medicine list from the patient's records, the patient's own additions, and an encrypted QR code to share it.

**Architecture:** Static pages on GitHub Pages, no build step. Logic lives in small ES modules under `js/` that never touch the DOM, so Node's built-in test runner covers them. Pages (`index.html`, `share.html`) import those modules and render with `textContent` only.

**Tech Stack:** Plain HTML and JavaScript (ES modules), fhirclient.js 3.0.1, Web Crypto, WebAuthn PRF, CompressionStream, qrcode-generator 1.4.4, RxNav REST, Node 26 `node --test`, mkcert for local https.

**Spec:** `docs/superpowers/specs/2026-11-17-brown-bag-design.md`

## Global Constraints

- Work happens on branch `brown-bag-v1`. After every commit, run `git push origin brown-bag-v1`. Never push to `main`, never merge, never open a pull request without Tyler saying so. `main` is the live site.
- The repo is public. No secrets, no real patient data, no `.certs/` files in any commit.
- WCAG 2.2 level AA on every page: contrast 4.5 to 1, labels on every control, 44 by 44 point targets, visible focus, no color-only meaning, works at the largest text size, respects reduce motion.
- Disclaimer copy, exact, on `index.html` and `share.html`: "This list is what you and your records say. Your care team confirms it."
- Commit messages are one short line in Tyler's voice: no dashes, no semicolons, no bullet lists. End each with the Co-Authored-By and Claude-Session lines from the session.
- Stage explicit paths. Never `git add -A`.
- No npm packages, no build step. Browser libraries load from `cdn.jsdelivr.net/npm/` with an exact version.
- Keep fhirclient.js at 3.0.1 and the starter's `.read` scope style.
- All system-derived text goes into the page with `textContent`, never `innerHTML`.
- Super simple for a non-technical patient: large text, one main screen, plain labels.
- QR error correction level M. Max QR payload `QR_MAX_BYTES = 2331`.
- PBKDF2 SHA-256, 600000 iterations. AES-GCM 256, 12-byte IV.
- Share code: 6 digits from `crypto.getRandomValues`. Link secret: 16 random bytes.
- Testing runs over https on Tyler's Mac at port 8443. No tunnelling services.

## Review Focus

- Patient with no medicines in their records: empty "From your records" section that says so, and the QR still works with additions only. Test in Task 1 and Task 3.
- A record with no RxNorm code or no name: kept, deduplicated by text, shown as "Unnamed medicine" if no name at all. Never dropped. Test in Task 1.
- List too long for one QR code: say so and keep the list on screen. Test in Task 3.
- Wrong, missing, or damaged share code or link on `share.html`: plain message, no partial list. Test in Task 3.
- Record text containing HTML such as `<b>Aspirin</b>`: shown as literal text. Test in Task 3 (bundle keeps it verbatim) and the manual check in Task 7.

### Task 2: Encrypted storage on the device

**Files:**
- Create: `js/vault.js`
- Create: `tests/vault.test.mjs`

**Interfaces:**
- Produces:
  - `deriveKeyFromPin(pin: string, salt: Uint8Array) -> Promise<CryptoKey>`. PBKDF2 SHA-256, 600000 iterations, AES-GCM 256, not extractable.
  - `keyFromPrf(prfOutput: ArrayBuffer) -> Promise<CryptoKey>`. HKDF SHA-256, empty salt, info `"brownbag-vault"`.
  - `encryptJSON(key, value) -> Promise<string>`. Base64url of `iv (12) + ciphertext`.
  - `decryptJSON(key, blob) -> Promise<any>`. Throws `VaultError` with `code "locked"` on a wrong key or damaged blob.
  - `PatientData = { additions: Addition[], stopped: { [medKey]: isoDate } }`
  - `Addition = { id, rxcui, name, dose, frequency, addedAt }`. `rxcui` is `null` for free text.
  - `loadPatientData(storage, key, patientId) -> Promise<PatientData>`. Storage key `"brownbag:data:" + patientId`. Nothing stored gives `{ additions: [], stopped: {} }`.
  - `savePatientData(storage, key, patientId, data) -> Promise<void>`
  - `storage` is anything with `getItem` and `setItem` (localStorage in the browser, a Map wrapper in tests).
  - `exportBackup(storage, key) -> Promise<string>`: JSON text `{ app: "brownbag", version: 1, data: { [patientId]: <encrypted blob> } }` holding every `brownbag:data:*` entry, still encrypted.
  - `importBackup(storage, key, text) -> Promise<number>`: checks each blob decrypts with `key`, writes them back, returns how many patients were restored. Throws `VaultError` `"bad-backup"` for text that isn't a Brown Bag backup and `"locked"` for one made with a different key.

### Task 3: Encrypted share link

**Files:**
- Create: `js/share.js`
- Create: `tests/share.test.mjs`

**Interfaces:**
- Consumes: `MedItem` (Task 1), `Addition` (Task 2).
- Produces:
  - `buildShareBundle({ patient: { name, birthDate }, current: MedItem[], additions: Addition[], stopped: (MedItem & { stoppedAt })[] }, now: Date) -> Bundle`. A FHIR Bundle of `type "collection"`, `timestamp` = `now`, one Patient entry, then one MedicationStatement per medicine:
    - From records: `status "active"`, `note[0].text = "From records: " + source`.
    - Added by patient: `status "active"`, `informationSource = { reference: "Patient/self" }`.
    - Patient says stopped: `status "stopped"`, `informationSource = { reference: "Patient/self" }`, `effectivePeriod.end = stoppedAt`.
    - `medicationCodeableConcept` carries the RxNorm coding when there is one and `text` = name always. Dose and frequency go in `dosage[0].text`.
  - `groupShareBundle(bundle) -> { patient, madeAt, fromRecords: Row[], addedByPatient: Row[], patientSaysStopped: Row[] }`. `Row = { name, detail }`.
  - `packShare(bundle, baseUrl) -> Promise<{ url, code }>`. Compress the JSON with `CompressionStream("deflate-raw")`. Key = PBKDF2(code, salt = link secret, 600000) into AES-GCM 256. `url = baseUrl + "share.html#v1." + base64url(linkSecret + iv + ciphertext)`.
  - `unpackShare(fragment, code) -> Promise<Bundle>`. `fragment` is everything after `#`. Throws `ShareError` with `code "bad-link"` (no `v1.` prefix or too short) or `"wrong-code"` (decrypt fails).
  - `QR_MAX_BYTES = 2331`, `fitsInQr(url) -> boolean` by UTF-8 byte length.

### Task 4: Drug name lookup

**Files:**
- Create: `js/rxnorm.js`
- Create: `tests/rxnorm.test.mjs`

**Interfaces:**
- Produces:
  - `searchDrugs(term, fetchFn = globalThis.fetch) -> Promise<{ rxcui, name }[]>`. First calls `https://rxnav.nlm.nih.gov/REST/drugs.json?name=<encoded term>` and keeps `conceptProperties` from groups with `tty` `SCD` or `SBD`. If none, calls `https://rxnav.nlm.nih.gov/REST/approximateTerm.json?term=<encoded term>&maxEntries=8` and keeps candidates that have a `name`. No duplicate rxcui. At most 10 results. A blank term returns `[]` without calling.
  - Throws `RxNormError` when a request fails or isn't ok. The page then offers free-text entry.
  - `ingredientsFor(rxcuis: string[], fetchFn = globalThis.fetch) -> Promise<Map<rxcui, { rxcui, name }>>`. For each rxcui calls `https://rxnav.nlm.nih.gov/REST/rxcui/<rxcui>/related.json?tty=IN` and keeps the first `IN` concept. At most 4 requests at a time. An rxcui whose request fails is left out of the map, so grouping falls back to the exact product.
