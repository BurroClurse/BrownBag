# Add Form Lists and Check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "How much" and "How often" become pick lists that fit the medicine, picked answers go into the QR code as structured FHIR dosage, and Save checks the new medicine against the list and asks before adding a duplicate, a different dose, a look-alike or a stopped medicine.

**Architecture:** Two new DOM-free modules: `js/add-choices.js` (the lists and what each choice means as FHIR) and `js/add-check.js` (comparing a new medicine with the list). `js/view.js` saves the structured answers, `js/share.js` writes them into the MedicationStatement, and `js/app.js` draws the lists and the confirmation panel.

**Tech Stack:** Plain ES modules, Node's test runner, headless Chrome over CDP for screen checks (scripts in the session scratchpad, as before), axe-core 4.10.2.

**Spec:** `docs/superpowers/specs/2026-11-22-add-form-design.md`

## Global Constraints

- Static site, no new libraries.
- WCAG 2.2 AA: every list labelled, the panel announced, 44 px targets, works at large text sizes.
- The QR stays inside its version 40-M budget; if a list no longer fits, the existing "too long for one QR code" path shows.
- No browser `confirm()`; the check is a panel in the page.
- Every check ends in a choice the patient makes; nothing is ever blocked.
- Commit messages: one short line in Tyler's voice, no dashes, plus the attribution lines. Stage explicit paths.
- Tests: `node --test "tests/*.test.mjs"` from `BrownBag/`.

## Review Focus

1. A record whose schedule is long text ("1 by mouth once a day") and a new pick "Once a day" of the same drug and dose: counts as the same dose and schedule (case 2), not a different one. Pinned in Task 3.
2. Picking a medicine, then typing over its name: the "How much" list goes back to the general list and the rxcui is dropped. Pinned in Task 4's headless check.
3. Tapping Save twice while the ingredient lookup is running: one panel, never two additions. Pinned in Task 5's headless check.
4. No connection (RxNav refused): Save still finishes within 5 s, a same-code duplicate and a look-alike are still caught. Pinned in Task 5's headless check.
5. Large text (200%) and VoiceOver: the panel's heading takes focus and every button is reachable. Pinned in Task 5's headless check (focus, axe, 200% screenshot).

### Task 3: The check

**Files:**
- Create: `js/add-check.js`
- Modify: `sw.js` (add `"./js/add-check.js"`)
- Test: `tests/add-check.test.mjs`

**Interfaces:**
- Produces: `checkAddition(candidate, list, ingredientOf) -> null | { kind: "stopped" | "duplicate" | "different" | "lookalike", match }`
  - `candidate`: `{ name, rxcui, dose, frequency }`
  - `list`: `Array<{ key, name, rxcui, dose, frequency, origin: "records" | "claims" | "added", id?, stoppedAt? }>`, stopped entries carry `stoppedAt`
  - `ingredientOf`: `Map<rxcui, { rxcui }>` (may be empty)
  - `match`: the list entry that triggered it.
- Rules (spec order, first match wins): same medicine = same rxcui, or same ingredient key, or (either has no rxcui and the first words of the names are equal, ignoring case). Stopped + same medicine → "stopped". Same medicine + same dose and schedule → "duplicate", otherwise "different" (including when either side has no dose or schedule). Not the same medicine, and the first words (5+ letters) differ by 1 or 2 letters (edit distance) → "lookalike".
- Same dose and schedule: compare after lowercasing, "twice" → "2 times", "once" → "1 time", "½" → "0.5", "1½" → "1.5", plural "s" dropped; a match when the candidate's words are found inside the entry's words (records often say "1 by mouth once a day").

- [ ] **Step 1: Write the failing tests**

```js
const rec = (o) => Object.assign({ key: "rx:314076", name: "lisinopril 10 MG Oral Tablet", rxcui: "314076", dose: "1 tablet", frequency: "1 by mouth once a day", origin: "records" }, o);
test("same code, same dose and schedule is a duplicate, even inside longer record wording", () => {
  assert.equal(checkAddition({ name: "lisinopril 10 MG Oral Tablet", rxcui: "314076", dose: "1 tablet", frequency: "Once a day" }, [rec()], new Map()).kind, "duplicate");
});
test("same ingredient, different strength is different", () => {
  const ing = new Map([["314076", { rxcui: "29046" }], ["314077", { rxcui: "29046" }]]);
  assert.equal(checkAddition({ name: "lisinopril 20 MG Oral Tablet", rxcui: "314077", dose: "1 tablet", frequency: "Once a day" }, [rec()], ing).kind, "different");
});
test("same medicine with no dose on either side is different, never a duplicate", () => {
  assert.equal(checkAddition({ name: "lisinopril 10 MG Oral Tablet", rxcui: "314076", dose: null, frequency: null }, [rec()], new Map()).kind, "different");
});
test("a stopped medicine wins over a duplicate", () => {
  const r = checkAddition({ name: "metformin 500 MG", rxcui: "861007", dose: null, frequency: null }, [rec({ key: "rx:861007", name: "metformin 500 MG", rxcui: "861007", stoppedAt: "2026-11-20" })], new Map());
  assert.equal(r.kind, "stopped");
  assert.equal(r.match.stoppedAt, "2026-11-20");
});
test("look-alike names that are different medicines", () => {
  const r = checkAddition({ name: "hydroxyzine 25 MG Oral Tablet", rxcui: "995258", dose: null, frequency: null }, [rec({ key: "rx:1", name: "hydralazine 25 MG Oral Tablet", rxcui: "905199" })], new Map());
  assert.equal(r.kind, "lookalike");
});
test("a hand-typed near miss is a look-alike (Tyler, 2026-11-22)", () => {
  assert.equal(checkAddition({ name: "Lisinoprill", rxcui: null, dose: null, frequency: null }, [rec()], new Map()).kind, "lookalike");
});
test("a hand-typed exact name is the same medicine", () => {
  assert.equal(checkAddition({ name: "Lisinopril", rxcui: null, dose: "1 tablet", frequency: "once a day" }, [rec()], new Map()).kind, "duplicate");
});
test("short names and unrelated names pass", () => {
  assert.equal(checkAddition({ name: "Zinc", rxcui: null, dose: null, frequency: null }, [rec({ name: "Iron", rxcui: null })], new Map()), null);
  assert.equal(checkAddition({ name: "atorvastatin 20 MG", rxcui: "617310", dose: null, frequency: null }, [rec()], new Map()), null);
});
```
